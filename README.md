# 🎓 Student Task Manager

A simple and modern task manager designed for students.

## ✨ Features

- ➕ Add tasks
- ✅ Complete and uncomplete tasks
- 🗑️ Delete tasks
- 🔎 Search tasks
- 🎯 Filter tasks
- 🔴 Task priorities
- 📅 Deadlines
- ⚠️ Deadline warnings
- 📊 Progress bar
- 🌙 Dark mode
- 💾 LocalStorage
- 📱 Responsive design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🚀 How to use

1. Open `index.html` in your browser.
2. Add your tasks.
3. Set a priority and deadline.
4. Track your progress.
